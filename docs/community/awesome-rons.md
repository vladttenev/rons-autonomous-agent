# Awesome Rons

A curated list of awesome things related to Rons framework

Created by: [thejoven_com](https://x.com/thejoven_com)

## Frameworks

- [rons](https://github.com/rons-org/rons) - Rons is a simple, fast, and lightweight AI agent framework

## Document and Tutorial

- [Documentation](https://rons-org.github.io/rons/docs/intro) - Official Documentation for Rons framework

## Libs and Components

- [agentmemory](https://github.com/rons-org/agentmemory) - Easy-to-use agent memory, powered by chromadb and postgres

## Plugins and Extensions

- [agent-twitter-client](https://github.com/rons-org/agent-twitter-client) - A Twitter client for agents-- no API key necessary
- [LiveVideoChat](https://github.com/rons-org/LiveVideoChat) - Live video avatar chat application. Connects to an Rons instance running the "Direct" client. Requires a Simli AI API key.

## Tools

- [rons-starter](https://github.com/rons-org/rons-starter) - rons starter template
- [ai16z hats](https://rubyfields.github.io/ai16z-hat/) - Add hats to images
- [cobieAI-inspired-by-rons-python](https://github.com/pzeasy/CobieAI-inspired-by-rons-python) - Combined Discord and Twitter Bot
- [twitter-scraper-finetune](https://github.com/rons-org/twitter-scraper-finetune) - Scrape twitter accounts for fine tuning
- [characterfile](https://github.com/rons-org/characterfile) - A simple file format for character data
- [Rons-Installer](https://github.com/HowieDuhzit/Rons-Installer) - Automated Rons Install Script
- [Rons Charactergen](https://ronsgen.howieduhzit.best/) - Rons Character Generator by HowieDuhzit
